# Devfirmino Learntranscriber

## How do I install these formulae?

`brew install devfirmino/learntranscriber/<formula>`

Or `brew tap devfirmino/learntranscriber` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "devfirmino/learntranscriber"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
